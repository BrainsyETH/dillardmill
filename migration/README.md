# Squarespace import (historical)

The content from the Squarespace site has been imported into the repo:
`src/lib/content/photos.json` (property photographs with source URLs),
`src/lib/content/journal.json` (journal posts at their original paths) and
`public/images/`. See `docs/GUEST-EXPERIENCE.md`.

What remains here:

- `pine-valley-data.json` — the original hand-collected summary of the stays.
- `parse-squarespace-xml.mjs` and `export-instructions.md` — for parsing a
  Squarespace WordPress-format export, if one is ever needed for a check.
